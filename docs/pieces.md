# Pieces

`worldMiniatureGeometry(type, house, color, detailed)` returns the current production sculpt for `footman`, `knight`, `siege-engine`, `ship` or `dragon`. `worldMiniatureColor(house, fallback)` preserves its paint policy. `miniatureGeometry` is also exported for the original configurable builder. `companyGeometry(type, detailed)` returns the current combined company geometry.

Use a vertex-colored material. Geometries retain the game's original units and attributes; the consumer owns disposal. This round does not replace the sculpts with the new army system. The gallery shows all ten demo identities and isolated current companies. Demo emblems are original abstract shapes; hosts inject their own SVGs before building pieces.
