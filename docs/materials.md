# Materials

`CastleMaterial(assets?)` preserves masonry, wood, roof, glow and snow shader tags. `setSeason(dusk, winter, full)` sets the original seasonal treatment. `setSurfaces({ castle: { albedo, roughness, normal } })` optionally injects host-owned texture arrays; call without an argument to clear them. There is no world subscription or sampler scheduler.

`ComplexMaterial` adds per-instance dither coverage; apply `addFadeAttribute(geometry, count)`. `HeroMaterial` adds metre-space rock detail. `CityMaterial` adds the shared instance house/curtain attributes; `PhysicalMaterial` packs attributes and adds the physical city's fade clock. `IceWallMaterial` is the board ice shader; `WallIceMaterial` is the physical profile shader.

`AssetMaterials(changed, installKit)` owns optional CC0 textures/model modules. `register(material, surface)` accepts `wood`, `paper`, `stone`, `metal`. Enable with `setQuality(true)`, call `prepare()` for maps and `afterPaint()` for the model. `programsReady()` reports map preparation completion. Always dispose the owner; it retains procedural fallback on optional load failure. Asset notices and the complete CC0 legal text accompany the GLB/WebP files in `src/materials/assets/licenses/`.

`SurfaceArrays(renderer)` loads the six-layer terrain or two-layer masonry KTX2 albedo/normal/roughness arrays with the bundled three.js Basis transcoder. `load('terrain' | 'masonry')` resolves a `SurfaceArraySet`; `surfaceArrayMaterial(set, layer)` is a standalone inspection material. The owner disposes arrays and workers. Poly Haven CC0 attribution accompanies every source array under `assets/world/`. Production splat GLSL is exported as `surfaceDeclarations`, `surfaceColor`, `surfaceNormal`, `surfaceRoughness`; it requires host terrain sampling inputs, unlike the single-layer swatch.

`waterSurfaceMaterial(uniforms, full, view)` preserves production water optics, animated geometry, Fresnel and caustics. Hosts inject the coastline/depth field and presentation clock through `WaterUniforms`; `applyWaterColors` and `attachCaustics` are optional adapters. `waveHeight` and `waveSpectrum` expose the original wave law. The gallery uses a synthetic constant optical field rather than game geography. `oceanRings(layout)` and `adaptiveHeightGeometry(...)` expose original adaptive ocean/seabed topology without terrain streaming. The host owns every returned geometry and material.

`waterEnvironment(renderer, outdoor)` builds a tiny procedural PMREM water radiance target; dispose the returned target. `SurfaceFinish(tableMesh, mapMesh, assetMapsActive?)` supplies original procedural wood/paper normals as fallback behind loaded CC0 maps. `setQuality` toggles them; `dispose()` releases the owned textures.

The compiled gallery ships `licenses.txt` with the full GPL, MIT, Apache-2.0 and CC0 texts, including three.js, meshoptimizer and Basis Universal notices. The catalogue footer links to it. The decoder/transcoder bytes come unmodified from three.js 0.186.1.
