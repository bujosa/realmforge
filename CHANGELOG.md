# Changelog

## 0.1.0 — 2026-10-22

- Extract standalone procedural castles, cities, pieces, nature, props, materials, dragons, effects and tokens from Swords and Ravens.
- Add animated instanced companies, injectable heraldry and public wildling-threat presentation.
- Provide a searchable responsive gallery with LOD/palette controls, orbit/fly/walk exploration and shareable QA links.
- Organize studies by domain and refine ten utility composer modules with original procedural joinery and open silhouettes.
- Make headless Chrome/WebKit QA portable with a local Playwright dependency, configurable temporary preview and gitignored output.
- Add public source-package metadata, licensing/provenance documentation, contribution guide, CI and an owner-enabled GitHub Pages workflow.

The package remains private for npm publication. Repository visibility and deployment are controlled by its owner.
