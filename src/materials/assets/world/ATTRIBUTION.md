# World surface textures

Source: Poly Haven (https://polyhaven.com/license), CC0. The KTX2 arrays were assembled by Look L0 from 512 × 512 versions of these assets, with mipmaps. Each material contributes albedo, OpenGL normal and roughness maps.

Terrain layers, in order:

0. Leafy Grass — https://polyhaven.com/a/leafy_grass
1. Sparse Grass — https://polyhaven.com/a/sparse_grass
2. Farm Furrows — https://polyhaven.com/a/farm_furrows
3. Dirt — https://polyhaven.com/a/dirt
4. Coast Sand 04 — https://polyhaven.com/a/coast_sand_04
5. Rock Face 03 — https://polyhaven.com/a/rock_face_03

Castle layers, in order:

0. Castle Wall Slates — https://polyhaven.com/a/castle_wall_slates
1. Clay Roof Tiles — https://polyhaven.com/a/clay_roof_tiles
