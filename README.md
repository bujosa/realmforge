# Realmforge

Procedural low-poly medieval miniatures, castles and cities for [three.js](https://threejs.org),
with a visual QA gallery for every component.

Realmforge is extracted from the 3D board of the Swords and Ravens V3 client. Every model is built
in code (no external meshes), so each component can be inspected, varied and tested in isolation.

> Status: early extraction. The API is not stable yet.

## Gallery

```sh
npm install
npm run dev        # http://localhost:5199
```

Each component is a *story* in `gallery/stories/`. Open a story by its id, e.g.
`http://localhost:5199/#pieces/knight`.
